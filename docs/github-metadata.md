## Repository name

| Option | Pro | Contra |
| --- | --- | --- |
| **`multica-android-unofficial`** (recommended) | Search term "multica android" comes first; "unofficial" is visible in every link and clone URL. | Long. |
| `unofficial-multica-android` | Reads naturally. | Weaker for search, the important words come later. |
| `multica-android` | Short, best for search. | Can be mistaken for an official repository; avoid. |

Note: Apache 2.0 (section 6) grants no trademark rights beyond describing the origin of the work. Using "Multica" in the name to describe what the app is for, together with "unofficial", is the usual practice; a name without "Multica" would avoid the question entirely but is much harder to find.
