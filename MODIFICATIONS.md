## Base

- Upstream: Multica `v0.6.1` (upstream commit `2ea01ae4e`).
- Taken over: `apps/mobile`, `packages/core`, `packages/tsconfig`,
  `packages/eslint-config`, `LICENSE`, `NOTICE`. Server, web, desktop,
  documentation site, Docker and CI files of the upstream repository are not
  part of this repository.

## Summary of changes

- Android build of the mobile app: native notification module
  (`apps/mobile/modules/rb-notify`), Expo config plugins, build and release
  scripts, Android-specific fixes and features in `apps/mobile`.
- Unofficial app identity: applicationId `net.recordingbeats.multica.unofficial`,
  display name "Multica (Unofficial)". Logo, the name "Multica" and the
  copyright/attribution notices shown in the UI are unchanged.
- Standalone workspace: root `package.json`, `pnpm-workspace.yaml` and
  `pnpm-lock.yaml` reduced to the app and the packages above; the
  `eslint-config` package lost its Next.js preset.
- Documentation for this repository: `README.md` and a GitHub Pages landing
  page (`docs/`, with screenshots and a social preview image);
  `apps/mobile/README.md` rewritten for building, signing and
  connecting the Android app (it was the upstream iOS guide);
  `apps/mobile/AGENTS.md` adapted to the standalone Android repository
  (no monorepo, web/desktop or iOS-first references); a note on top of
  `apps/mobile/docs/markdown-rendering-adr.md` that it is a historical
  upstream decision record.
- Version 2.0.0 (see `CHANGELOG.md`): tablet layout, issue-list views,
  sorting, multi-select and batch actions, wakeups, autopilots, runtimes,
  an encrypted on-device timeline cache and performance work in
  `apps/mobile`. New dependencies: `react-native-mmkv`,
  `react-native-nitro-modules` and `expo-crypto` (timeline cache),
  `@shikijs/engine-javascript` (development only); new Expo config plugin
  `apps/mobile/plugins/with-baseline-profile.js` (app baseline profile).
  End-to-end test flows and CI scripts of the development setup are not
  part of this repository.
- Comments only (no values or code changed): the `.env*` files,
  `app.config.ts`, `lib/debug-token-login.ts` and
  `scripts/check-release-bundle.sh` in `apps/mobile` no longer refer to
  iPhone-only scripts, the desktop/web apps or a missing `docs/ANDROID.md`.
